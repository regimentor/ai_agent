# AI Agent

An educational project created to learn software development in Rust and explore
interactions with local LLMs.

The project implements a modular Harness agent composed of multiple services.
Tasks are executed in isolated Docker containers to ensure safety and
reproducibility.

## Project Goals

- learn Rust and its software development practices;
- explore the capabilities and behavior of local LLMs;
- develop a modular Harness agent;
- execute tasks in isolated Docker containers.
